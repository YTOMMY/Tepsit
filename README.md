# Bassoni Tepsit

### webService_Bassoni
questo è un progetto eclipse maven che implementa un web service. <br>
dopo aver eseguito il comando mvn jetty:run si avvierà il servizio. <br>
per visualizzare la pagina jsp andare a http://localhost:8080/ <br>
per utilizzare l'API REST andare a http://localhost:8080/api/test/<nome\> (\<nome\> verrà restituito). <br>
